# Code of conduct

Chaku follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), in this repository, in the team's Linear and Discord, and anywhere else we work together.

In short: be kind and patient, assume good intent, criticise ideas and code rather than people, and make room for people who are new. Harassment, insults, discrimination and sharing someone's private information are not accepted.

**Reporting:** contact the maintainer, [@Chetardie](https://github.com/Chetardie), privately through GitHub or Discord. A dedicated contact address will be added when Chaku's domain is set up (D55). Reports are handled confidentially, and the maintainer applies the Contributor Covenant's enforcement guidelines.
